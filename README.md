# ExamSaathi Frontend

AI-powered CET preparation — topic quizzes, mock tests, and an AI tutor.

## Development

```sh
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Environment

Create `.env.local`:

```env
NEXT_PUBLIC_API_BASE_URL=https://examshaathi-backend.onrender.com/api
```

## Stack

- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Lucide React icons
- TanStack Query
